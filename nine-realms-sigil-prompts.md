## USAGE NOTES

**For Midjourney:** Copy prompt exactly, add `--v 6.1` at the end
**For Leonardo AI:** Use the prompt in "Alchemy" mode, set style to "Illustration" or "Graphic Novel"
**For Adobe Firefly:** Remove the `--ar` and `--style` flags, paste remainder as prompt
**For Ideogram:** Add `"style: illustration, no text"` as a style tag

**Recommended output:** 1024x1024px minimum, PNG with transparency if possible
**Color post-processing:** Bring into Canva and overlay your nation's accent color as a tint layer for web consistency
